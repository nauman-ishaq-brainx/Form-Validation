# Form Validation

A comprehensive form validation implementation that provides real-time feedback and input verification for a registration form. The validation includes password strength checks, email format validation, age restrictions, and more.

**Live Link:** [Form Validation](https://nauman-ishaq-brainx.github.io/Form-Validation/)

---

## 🚀 Features

- **Password Validation:**  
  - Minimum length of 8 characters  
  - Must include at least one uppercase letter, one lowercase letter, and one numeric character  

- **Password Confirmation:**  
  - Ensures the confirmation password matches the original password  

- **Age Validation:**  
  - Accepts ages between 18 and 151 years  

- **Contact Number Validation:**  
  - Verifies that the contact number is exactly 11 digits  
  - Allows the contact field to be left empty  

- **Name Validation:**  
  - Ensures both first and last names contain at least one character  

- **Email Validation:**  
  - Accepts multiple email addresses separated by commas  
  - Verifies each email against a standard email format  

- **Form Submission Control:**  
  - Submit button is disabled until all input fields are valid  

---

## 🛠️ Usage

- Open the live link and interact with the form.  
- Enter data in each field to view validation feedback in real-time.  
- Attempt to submit the form with invalid data to see error messages.  
- Correct the inputs to enable the submit button.
